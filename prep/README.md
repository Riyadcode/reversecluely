# prep/

Put your interview documents here: resume, job description, prep guides, notes
(PDF, DOCX, HTML, TXT or MD). arlclue loads every file in this folder at
startup, so it knows them from the first question.

Everything in this folder except this README is ignored by git, so your resume
and notes are never committed or pushed to GitHub.

- Short documents (a resume) are sent whole with each question.
- Long documents (a 100-page guide) are searched, and only the passages that
  match the question are sent, which keeps answers fast.

After adding or changing files while the app is open, click **Reload** in
Settings → Interview Prep Documents (or restart the app).
